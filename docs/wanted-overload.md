# WANTED OVERLOAD — 戦利品が敵を呼ぶ遠征

## ねらい

これまでの遠征は、勝つほど装備が増え、基本的には「より安定して次へ進める」構造だった。
戦闘単体には BREAK、改造コア、DEATH RIDE、寄り道拠点がある一方、10戦を通した物語は「報酬を取って強くなる」に寄りやすい。

WANTED OVERLOAD はこの向きを反転させる。

**戦利品は強化であると同時に、キャラバンの居場所を敵へ知らせる発信機でもある。**

強い物を積むほど追跡熱が上がり、次の戦闘には通常 Wave と別の追撃部隊が最初から混ざる。その代わり、高い追跡熱は以後の報酬品質を大きく押し上げる。

目標は「正しいビルドを完成させた」ではなく、

- あの特級を拾った瞬間に遠征が壊れた
- 追撃 MAX のまま DEATH RIDE で無理やり突破した
- 欲張ってレールガンを盗んだせいで次戦の砲兵に焼かれた

のように、一回の遠征を短い事件として思い出せること。

## ルール

追跡熱は 0〜6。

| 取得した戦利品 | 追跡熱 |
| -------------- | -----: |
| 標準           |     +1 |
| 希少           |     +2 |
| 特級           |     +3 |

通常の戦闘報酬だけでなく、戦場の武器箱から持ち出した武器も加算対象になる。
6を超えた分は切り捨てる。

報酬カードには選択前の追跡熱と、取得後の値を表示する。プレイヤーに隠して事故らせる仕組みにはしない。

## 追撃部隊

次戦開始時、通常 Wave や寄り道拠点の守備隊とは別枠で以下を配置する。

| 追跡熱 | 追加される敵                        |
| -----: | ----------------------------------- |
|      0 | なし                                |
|      1 | Rusher                              |
|      2 | Rusher + Basic                      |
|      3 | Rusher + Bomber                     |
|      4 | Rusher + Bomber + Basic             |
|      5 | Rusher + Bomber + Artillery         |
|      6 | Rusher + Bomber + Artillery + Heavy |

追撃隊は Wave の後半に足すのではなく、戦闘開始時点ですでに 68〜108m に侵入している。
高追跡熱では「準備してから通常 Wave を処理する」余白そのものを壊す。

## 欲張りへの報酬

追跡熱は報酬抽選の risk multiplier に `追跡熱 × 0.8` を加算する。
最大では +4.8。

そのため高追跡熱は単なる縛りではない。
追撃を生き延びるほど希少・特級を引きやすくなり、それを取ることでさらに危険な状態を維持する正のフィードバックになる。

狙う感情は「安全にしたい」より **「もうここまで来たなら全部積む」**。

## 既存システムとの関係

- **DEATH RIDE**: 高追跡熱の開幕混戦をさらに壊して返す、最も危険な解法になる。
- **BREAK**: Heavy を含む追撃 MAX の処理で重要度が上がる。
- **改造コア**: 追撃編成に対して、どの戦い方を採用したかがより強く出る。
- **寄り道拠点**: 守備隊 + 追撃隊が同居するため、物資庫の追加報酬が本当に欲張りな選択になる。
- **武器箱**: その場では即戦力だが、持ち出した時点で次戦の追跡熱を上げる。

## 今回あえて入れないもの

- 追跡熱を通貨で下げるショップ
- 安全にリセットできるボタン
- 追撃の細かな難易度スライダー
- メタ進行による追跡軽減

最初から逃げ道を増やすと、遠征が再び「安定化の最適化」へ戻るため。
まずはピーキーに振り、プレイ結果を見て必要なら後から逃げ道を足す。

## 評価基準

この変更は平均クリア率を上げるためのものではない。
以下を満たすかで判断する。

1. 報酬カードで、性能だけでなく「これを取った後の地獄」を比較する瞬間が生まれるか。
2. 第5戦以降の開始10秒が、毎回同じ通常 Wave 処理ではなくなるか。
3. 敗因を「火力不足」ではなく「欲張った選択」として説明できるランが生まれるか。
4. 追跡 MAX 到達時に、DEATH RIDE を押すか温存するかの強い決断が発生するか。
5. 一度の遠征を、装備名や事故の組み合わせで人に話したくなるか。

成功条件は **「追跡 MAX で何が起きたかを覚えている」こと**。
