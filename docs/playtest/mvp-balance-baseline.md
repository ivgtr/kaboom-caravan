- Date: 2026-08-11

- Seeds: `1 / 42 / 2026`

- Reward policy: 現在のSubより上位のRocket／Railgunを優先し、それ以外はModule
- Command: `REPORT_BALANCE=1 npm test -- src/game/session/mvpRun.test.ts --reporter=verbose`

報酬選択の思考時間と演出待ち時間は含めない。ゲーム内のTIME SCOREも同じく、
各Combatの60Hz tickだけを合計する。数値は自動戦闘の回帰基準であり、人間の想定
プレイ時間ではない。

## 今回の調整意図

- 初期SubをRailgunからScatter Cannonへ変更し、1斉射を27から21ダメージへ抑制
- 通常敵5種のHPとBattle 1〜9の物量を増やし、後半ほど複数役割が重なる構成へ変更
- BossをHP 420 / Armor 5からHP 320 / Armor 3へ変更し、HP壁ではなく攻撃回避を主な脅威に変更
- 弾薬上限を30から50へ増やし、増加した敵数に対してMainを継続使用できるよう変更
- Frontlineの自然後退を2.5から0.5へ抑え、見えない敗北より敵の接触・射撃を難易度の中心に変更

## Findings for User Playtest

- 3 Seedすべてが全10戦を完走し、Boss戦は通常戦から極端に乖離しない21.8〜26.6秒になった。
- 通常戦は後半ほど長くなり、Battle 9ではBossと同等の戦闘時間になるケースがある。
- 初期Scatterは射程26・21ダメージの近距離補助で、Rocket／Railgun取得後は自動方針が置換を選ぶ。
- 最低HPは7〜61とBuild・回避結果による幅があり、Seed 2026は勝利可能だが再調整候補となる厳しさ。
- 敵弾は各Runで6発回避され、遠距離型に対する後退とESCが実際の生存率へ寄与する。
- 自動戦闘時間は126〜143秒。人間操作でも目標10〜20分へ届かない場合は、HPの一括増加ではなくEncounter数またはWave構造を再検討する。

次の変更では、手動プレイのBattle別TIME SCOREと敗因をこの基準へ比較する。
