## Findings for User Playtest

- 3 Seedすべてが全10戦を完走し、Boss戦は15.7〜15.8秒。強化武器に対してHP 440でも削り切れる。
- 追加した物量によりBattle 1〜4は7.6〜16.5秒、Battle 9は11.9〜20.1秒となり、通常戦にも密度差が生まれた。
- 初期Scatterは5 Pelletを接近時にまとめて当てる武器となり、Rocket／Railgunは範囲・貫通で異なる更新動機を持つ。
- 最低HPは65〜73。固定戦略では安定しているため、手動プレイではパリィ失敗時の圧力を重点確認する。
- 各Runで9回のパリィが成功し、敵弾命中は3〜4発まで減少。Q入力が防御・反撃・リソース循環へ実際に寄与する。
- 自動戦闘時間は106〜124秒。人間操作でも目標10〜20分へ届かない場合は、HPの一括増加ではなくEncounter数またはWave構造を再検討する。

次の変更では、手動プレイのBattle別TIME SCOREと敗因をこの基準へ比較する。
