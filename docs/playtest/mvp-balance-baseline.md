# MVP自動バランス基準

- Date: 2026-08-11
- Simulation: fixed 60Hz
- Seeds: `1 / 42 / 2026`
- Strategy: 距離37前後、Bossは距離60前後を維持し、Resourceに応じてMain／Subを切替
- Reward policy: Moduleを優先し、存在しない場合は先頭候補
- Movement: 全敵が画面外120から役割別の一定速度で進入し、距離による減速なし
- Command: `REPORT_BALANCE=1 npm test -- src/game/session/mvpRun.test.ts --reporter=verbose`

Reward選択の思考時間、演出待ち時間、操作の迷いは含まない。数値は自動戦闘の回帰基準であり、
人間の想定プレイ時間ではない。

敵弾の「回避」は、発射後にPlayerへ命中せず寿命切れとなった弾を指し、
`発射数 - 命中数`で集計する。

## Findings for User Playtest

- Battle 1〜5は約4.8〜6.5秒、Battle 10は約29.7秒で、戦闘時間配分が大きく偏る。
- 自動戦闘時間は約86秒で、要件の10〜20分とは大きな差がある。
- Artillery弾はBattle 7／8で各1発発射され、代表戦略では全弾命中した。
- Bossは距離60前後を維持する戦略にも1発を命中させ、完全に無力化されなくなった。
- Reward方針がModule優先のため、全Seedで武器は初期構成のまま。Module差によるHP差は出ている。
- Main／Sub比率は全体では均衡するが、Boss戦はRailgun 12発のみで完結する。
- 近接距離による減速を廃止し、通常速度をBasic 5.5、Rusher 8、Heavy 4、Artillery 5.5、Bomber 8、Boss 2.5へ再設定した。

これらはバランス変更の根拠ではなく、Phase Fで人間が体感を確認するための観測点とする。
