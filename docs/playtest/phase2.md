- 対象コミット: `55a32d7`
- 目的: 距離、前線、主副武器、共有リソース、特殊能力の方向性を確認する
- 結果: 2026-08-10 推奨案で承認済み（[ADR 0002](../adr/0002-combat-loadout.md)）


| 操作       | キー                     | 仮仕様                                        |
| ---------- | ------------------------ | --------------------------------------------- |
| 後退・前進 | `A` / `D` または左右キー | 位置0〜80                                     |

## 確認シナリオ

### 1. 距離による武器差

最寄り敵との距離と命中時Damageを確認する。

- 機関砲は12〜38mで本来のDamageになる
- レールガンは30〜72mで本来のDamageになる
- 適正距離外ではHUDに表示されるDamageが低下する

近づいて機関砲を使う場合と、安全圏からレールガンを使う場合で、位置判断が変わるかを見る。

### 2. 前線とリスク

前進して4つの色分けされた領域を移動する。

- 安全圏: ×1.0
- 前線: ×1.3
- 危険圏: ×1.7
- 敵陣付近: ×2.5

敵が前線へ圧力をかけると黄色い前線マーカーが後退し、撃破すると押し上がる。現段階の倍率は将来の3択報酬へ反映する予定で、まだ実報酬は発生しない。

### 3. リソースとOverheat

機関砲を長押しし、Ammo、Energy、Heatの変化を見る。Heatが100になるとOverheatし、60まで冷えるまで武器を使用できない。

Overheat付近で`Q`を使い、後退と排熱が距離・リソース判断として有効かを見る。

### 4. 主武器と副武器

機関砲とレールガンを使い分ける。

- 機関砲: 低消費、短Cooldown、適正中距離
- レールガン: Ammo 2、Energy 32、Heat 24、Cooldown 2.2秒、適正長距離

同じリソースを奪い合うため、レールガン使用後は機関砲や緊急ブーストの余裕が減る。

## 確認したい判断

次フェーズへ進む前に、以下を確定する。

1. 装備slotは「主武器1、副武器1、Module 4」を初期案とする
2. 同じModuleの重複装備はMVPでは不可とする
3. 特殊能力は現在の「緊急後退＋排熱」を継続する
4. Heat、Energy、Ammoは主副武器で共有する
5. 前進位置に応じて報酬倍率が上がる現在の方向性を継続する

上記は推奨初期案であり、数値はフェーズ6まで継続調整する。

## 決定結果

5項目すべてを推奨初期案のまま採用した。装備枠、重複規則、特殊能力、共有リソース、前線報酬の方向性は確定し、個別のダメージ、消費量、Cooldown、報酬倍率はバランス調整値として扱う。
