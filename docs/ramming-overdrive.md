# RAM / 衝角戦闘

## 目的

直近の改修で BREAK、DEATH RIDE、WANTED OVERLOAD、REDLINE と「危険な選択」は増えた一方、通常時の攻撃はまだ射撃ボタン中心です。

この変更では、既存の前進 + 急加速をそのまま攻撃手段へ変えます。新しいボタンやゲージは増やしません。

狙いは、敵の残HPと自分の速度を見て「これは轢き切れる」「これは止められる」と瞬時に賭ける局面を作ることです。

## ルール

前進しながら急加速し、速度 8 以上で敵へ接触すると RAM が発生します。

RAM の基礎ダメージは以下です。

```text
28 + 現在速度 × 2 - 敵Armor
```

最大速付近ではおおむね 60 台のダメージになります。

- Rusher / Bomber / Basic: 高速なら基本的に轢き抜けられる
- Artillery: 十分に速度が乗っていれば狙える
- Heavy: 無傷なら基本的に止められる。射撃で削ってから狙う対象
- Boss: フィニッシュ用途以外で突っ込むのはかなり危険

## 成功: ROADKILL

RAM 一発で敵を倒し切った場合は、車体ダメージも反動もありません。

敵は通常の `enemy-killed` として処理されるため、既存の以下のループへそのまま接続されます。

- 前線押し上げ
- 戦利品ドロップ
- onKill 系モジュール
- 撃破演出 / 撃破音
- Wave 完了判定

Ammo 0 のときに ROADKILL した場合は、PR #11 の REDLINE salvage がそのまま発動し、10 Ammo を回収します。

つまり弾切れ後は「HPを弾に変えて撃つ」だけでなく、「残HPの少ない敵へ突っ込んで弾を奪う」という別の comeback line が生まれます。

## 失敗: CRASH

RAM で倒し切れない場合、敵を8m押し飛ばし、0.65秒の短い硬直を与えます。

代わりにプレイヤーは以下を受けます。

- 速度を反転し、大きく後方へ弾かれる
- 敵の接触威力とサイズに応じた車体ダメージ
- 車体ダメージで0 HPになればそのまま敗北

CRASH damage:

```text
max(10, round(敵ContactDamage × 0.75 + 敵Radius × 2))
```

「当たれば最低限敵を押し返せる」ため完全な空振りにはしませんが、HeavyやBossへ雑に突っ込むほど戦況は悪化します。

## 既存システムとの関係

### REDLINE

Ammo 0 の ROADKILL は既存 salvage をそのまま利用します。

`弾切れ → HPを使って射撃` と `弾切れ → 弱った敵を轢いて弾を奪う` の二択になります。

### BREAK

Heavyを射撃でBREAKし、Armorを削ってからRAMで仕留める流れが成立します。

### DEATH RIDE

DEATH RIDEで追加した雑魚4体はRAMの標的にもなります。4秒の火力だけでなく、前へ突っ込んで群れを轢き抜ける荒い解法が生まれます。

### WANTED OVERLOAD

高追跡熱の開幕混戦では、後退して射撃するだけでなく、最初から前へ突っ込む選択が生まれます。失敗時のCRASHが重いため、高追跡熱ほど賭けになります。

## 参考にした体験

- Burnout 系の「高速で接触すること自体が攻撃になる」分かりやすさ
- Mad Max 系の「車体を武器として使うが、重い相手への衝突は自分も危険」という車両戦のリスク
- DOOM Eternal 的な「資源不足時ほど敵へ近づく」攻撃的な回復ループ

直接システムをコピーするのではなく、Kaboom Caravan の1D距離管理・既存Boost・REDLINEへ噛み合う形へ落としています。

## プレイテストで見ること

平均勝率より、以下を優先します。

1. 雑魚を轢き抜ける瞬間が射撃と明確に違う気持ちよさになっているか
2. Heavyの残HPを見て「あと少し削ればRAMで行ける」という判断が生まれるか
3. CRASHした瞬間に「欲張った」と理解できるか
4. Ammo 0 からROADKILLで10発奪って復帰する展開が記憶に残るか
5. RAMが射撃を置き換える万能解になっていないか

## 調整ノブ

最初に触る順番は以下です。

1. `minimumVelocity`
2. `baseDamage`
3. `velocityDamageMultiplier`
4. `reboundPushDistance`
5. `minimumCrashDamage`

まずは「雑魚は轢ける / Heavyは削ってから」を崩さず、CRASHの痛さを調整するのが安全です。
