# 寄り道の戦場拠点

## 狙い

PR #1の停止・操作ガイド、#2の前線突破、#3の改造コアを、**どこで何を取りに行くか**という遠征中の判断につなげる。

以前の進路選択は通常ルートと固定の代替ルートの2択で、整備所は無条件で耐久+30、物資庫は無条件でお宝+2・引き直し+1だった。同じ戦闘で無料の利益を得るため、代替ルートを選ぶかどうかの判断が薄かった。

今回、通常ルートは維持し、寄り道だけに追加の敵と回収拠点を用意する。回復が必要なら手前の整備所、装備を伸ばすなら奥の物資庫、戦利品の品質を狙うなら強敵、消耗を避けるなら街道を選ぶ。選択時には次の敵部隊・共通補修後の耐久・改造コアと、各ルートの負担／報酬を比較できる。

## 進路と条件

第4・7戦の前では4択。第10戦では、戦闘後の装備・品質を追う価値がなくなるため、街道と整備所の2択にする。進路選択の回数や追加の操作キーは増やさない。

| 進路   | 負担・回収条件                                                  | 報酬                                                           |
| ------ | --------------------------------------------------------------- | -------------------------------------------------------------- |
| 街道   | 通常の敵部隊。回収期限・追加の敵なし                            | 通常の戦利品                                                   |
| 強敵   | 従来どおり敵の耐久1.45倍、攻撃1.2倍、前線圧力1.25倍             | 補給品ドロップ率と戦利品品質の上昇。引き直しでも品質補正を維持 |
| 整備所 | ハナツノ1体追加。18秒以内に37〜53mを累計3秒確保                 | 耐久+40、最大耐久まで                                          |
| 物資庫 | ガレキガメ・ホウシダケ各1体追加。20秒以内に57〜73mを累計4秒確保 | 武器箱1個をその場で開封（3択）＋お宝2個                        |

数値の定義元は `src/game/data/routeDefinitions.ts`。次戦開始時の共通補修+15、通常の補給ドロップ、戦闘後の通常報酬は変更しない。物資庫の引き直しは無条件では増えなくなり、従来の戦闘中お宝の合計に応じた計算に含まれる。

## 戦闘中の判断

車両の中心が範囲内に入り、生きた敵の当たり判定が範囲に触れていない間だけ確保が進む。敵弾だけでは確保は止まらないが、通常どおり被弾する。停止を強制せず、範囲内での移動・射撃・パリィは自由。範囲から退いても進捗は消えず、期限だけが進む。

前線突破で敵を押し出して確保時間を作る、展開砲座で範囲を守る、連携機関で守備隊を片付ける、反攻弾を残して敵の接近を待つ、といった既存の操作を活かせる。危険なら一度退く、あるいは報酬そのものを諦めてよい。

**期限内に予定された敵部隊・増援と敵弾を全て排除した場合も、自動的に回収成功とする。** 車両の位置は問わない。空になった戦場で待たせたり、確保のために最後の敵を生かしておく動機を作ったりしない。味方の弾・補給品の回収待ちは、この代替達成条件を妨げない。

時間切れでも通常の戦闘は続く。追加した敵は残るが、追加の前線・耐久ペナルティはない。失効した拠点は後から回収できない。

## 処理順序とライフサイクル

- 判定は固定60Hzのシミュレーションに置く。描画・React・実時間はタイマーを変更しない。
- 移動、敵の行動、射撃・撃破、増援、前線圧力を解決した後に拠点を判定する。そのステップで押し出した／倒した敵は確保を妨げない。
- 耐久0または前線崩壊は回収より優先する。修理による復活はできない。期限ちょうどの累積確保／全滅は成功し、期限後の時間は確保に加えない。
- 一度だけ確定イベントを発行し、修理／お宝を加算する。武器箱は既存の報酬選択処理に渡し、同時に通常の武器箱を拾った場合は順に開く。武器箱と戦闘終了が同時なら箱を先に解決し、その後通常報酬へ進む。
- 武器箱選択中・手動／自動停止中は、進捗・期限・コア・突破時間を保持する。前線突破は拠点の時計を加速しない。
- 次戦は拠点なしから開始し、次の寄り道選択で新しい拠点を作る。遠征中の試行／成功数は結果画面に表示するが、永続保存形式は変えない。新規遠征で0へ戻る。
- 通常ルートには拠点を生成しない。追加守備隊は専用IDを使用し、既存の敵生成シーケンスや乱数を消費しない。通常ルートの固定3シードの期待値を維持する。

## 表示・操作

進路選択はネイティブのモーダルdialog。A/D・左右・Tab/Shift+Tabで全カードを巡回し、Space/Enterまたはタップで選択。Escでは閉じず、背景を操作できない。カード上の縦スクロールを許可し、選択カードの追従はdialog内だけで行う。

戦闘中は床の範囲マーカーとHUDで場所・期限・確保状況を示す。戦闘中に回収ルールを確認する際は一時停止を使う。確保／断念を状態通知し、報酬画面に結果を残す。追加のアニメーション・画像素材・依存パッケージはない。

## 確認手順

通常開始で第3戦後の装備選択まで進み、4つの進路を比較する。回収報酬は選択直後ではなく、実際の戦闘中に確定することを確認する。

```bash
npm ci
npm run check
npx playwright install chromium
npm run test:e2e -- tests/e2e/pause.spec.ts tests/e2e/breakthrough.spec.ts tests/e2e/combat-core.spec.ts tests/e2e/battlefield-objective.spec.ts
```

開発用URLは以下。拠点プレビューは、40HP・展開砲座・停止した高耐久の敵を用いる入力／表示確認用の状態であり、実戦の難度評価には使用しない。`debug`なしでは適用されない。

- `/?debug&routePreview`：第4戦前の比較・選択。
- `/?debug&routePreview=boss`：最終戦の街道／整備所。
- `/?debug&objectivePreview=repair`：35mから前進し、範囲内で確保すると耐久40→80。
- `/?debug&objectivePreview=salvage`：55mから前進し、確保後に武器箱を開く。
- `/?debug&objectivePreview=contested`：物資庫内に敵がおり、範囲へ入るだけでは確保できない。
- `/?debug&objectivePreview=expired`：短い期限で断念し、戦闘が続くことを確認。

## プレイテストで評価すること

自動テストが保証するのは進行・操作・再現性であり、面白さや最適な数値ではない。実プレイヤーによる選択率やクリア率の比較は未実施。

特に、回復が必要な弱い車両ほど守備隊が負担になる度合い、18／20秒の制限で諦める判断が成立するか、全滅による自動回収が主流になりすぎないか、物資庫で得る装備の強化量、スマートフォンで戦闘HUDと範囲の情報を追えるかを検証する。既存の強敵ルートの数値そのものは変更していない。
