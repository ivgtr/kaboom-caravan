# ADR 0002: 戦闘ロードアウトと共有リソース

- Status: Accepted
- Date: 2026-08-10

## 決定

フェーズ2の縦切りに対し、推奨初期案を採用する。

- 武器枠は主武器1、副武器1とする
- Module枠は4とし、同一Moduleの重複装備を認めない
- すべての武器を主武器・副武器のどちらにも装備可能とする
- 特殊能力は、電力を消費して短時間だけ接触攻撃・敵弾を防ぐ「迎撃パリィ」とする
- Heat、Energy、Ammoは主武器と副武器で共有する
- プレイヤーが前進するほど報酬倍率を上げ、危険と報酬を対応させる

4枠が埋まった後にModuleを取得した場合、MVPでは最も古いModuleを交換する。報酬選択時に現在の装備数と交換発生を表示する。

## 理由

主・副武器が同じリソースを奪い合うことで、武器選択がCooldownだけの使い分けにならない。迎撃パリィは後退の代用ではなく、敵の攻撃予兆へ能動的に応じる防御行動とする。成功時の反撃・電力回復・排熱・即時Cooldown回復によって、危険へ踏み込む判断と連続迎撃へ明確な見返りを与える。前進報酬は安全圏に留まり続ける最適化を抑える。

Moduleを4枠かつ重複不可にすると、10種類の候補間で構成を選ぶ余地を保ちつつ、同一効果の積み重ねによる極端な数値化を避けられる。

## 調整可能な値

次は設計上の決定ではなく、フェーズ8まで調整可能なバランス値とする。

- Heat、Energy、Ammoの最大値、消費量、回復量
- 迎撃パリィの消費電力、受付時間、反撃Damage、成功時の電力回復・排熱量、Cooldown
- 距離帯の境界と距離外Damage倍率
- 前線の押し引き量と報酬倍率
- 各武器・Moduleの個別数値

これらを変更しても、本ADRで定めた枠数、重複規則、共有リソース、特殊能力の役割は維持する。
