# ADR 0007: Energyを使う継続式の急加速

- Status: Accepted
- Date: 2026-08-11

## 決定

戦闘中の左`Shift`へ、入力中の移動方向へ継続的に車両を加速する「急加速」を割り当てる。

- 最高速度: 通常の1.6倍
- Energy消費: 毎秒18
- Energy回復: 急加速を要求していない間だけ通常どおり回復
- 再使用時間: なし
- 無敵時間: なし
- 攻撃: 急加速中も使用可能
- 発動条件: `A` / `D`または左右操作と、左`Shift`を同時に保持する
- 迎撃パリィとの同時入力: 迎撃パリィを優先し、急加速しない

Energyが空になると通常移動へ戻る。Energyが空の状態で左`Shift`を保持し続けても細かく発動と停止を繰り返さず、一度離してEnergyを回復させる必要がある。急加速を離した後は既存の慣性を保ちながら通常の最高速度へ戻る。

## 表現

保持中はキャラバンの小さなピッチ、速い車輪回転、増加した排気煙、進行方向と逆へ伸びる速度線を継続表示する。開始時だけ短い加速音を鳴らし、押しっぱなしで効果音を重ねない。

左下の移動操作群へ専用ボタンを置き、共有Energyの残量リングを同じ場所へ表示する。瞬間発動を示すBounceやCooldown表示は使用しない。

## 理由

0.22秒の単発移動は、継続的な距離調整や前線移動へ使いにくかった。保持式なら、Energyをどこまで移動へ配分するかをプレイヤーが直接調整でき、迎撃パリィや武器と共有Energyを奪い合う判断も生まれる。

副武器を`C`、迎撃パリィを`F`へ分離しているため、左手は移動と急加速、右手は攻撃と迎撃という役割を維持できる。

## 変更可能な数値

速度倍率と毎秒消費量はプレイテスト対象とする。ただし、保持式、方向入力必須、Energy消費、無敵なし、攻撃可能、迎撃優先という役割は維持する。
