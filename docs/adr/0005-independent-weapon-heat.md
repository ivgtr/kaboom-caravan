# ADR 0005: 武器別Heatと共通冷却能力

- Status: Accepted
- Date: 2026-08-11
- Supersedes: ADR 0002のHeat共有に関する決定

## 決定

主武器と副武器は、それぞれ独立したHeat値とオーバーヒート状態を持つ。

- オーバーヒートした武器だけを射撃不能にする
- Heatが60以下になると、その武器を再使用可能にする
- キャラバンの冷却能力は共通資源とし、Heatが残っている武器へ等分する
- AmmoとEnergyは引き続き主武器・副武器で共有する
- 迎撃パリィ成功時は両武器からHeatを30ずつ排出する
- 廃熱回収炉は、どちらの武器も過熱していない状態から最初のオーバーヒートが発生した時だけ作動する。両武器が冷えるまで再発動しない

## 理由

共有Heatでは、片方の武器を使い切った結果もう片方まで使用不能となり、主武器と副武器を使い分ける操作感が弱かった。武器別Heatなら、片方を休ませながらもう片方へ切り替える自然なローテーションが生まれる。

一方で冷却まで武器別性能にすると管理項目が増えるため、キャラバンのラジエーター性能は共通とする。両武器を同時運用すると冷却が分散するため、単純な連射だけが最適解にもならない。

Heatを扱う旧フィールドや互換変換は残さず、`player.weaponHeat.primary` と `player.weaponHeat.secondary` を唯一の状態とする。

## 表示

- 主武器・副武器ボタンの双方にHeatリングを常時表示する
- CooldownリングとHeatリングは別要素として同時に読めるようにする
- 75以上は警告色、100では赤色と振動で該当武器のロックを示す
- ゲーム内の赤熱・煙は該当武器から出し、車体全体の赤熱は両武器同時オーバーヒート時だけにする

## 調整可能な値

- オーバーヒート閾値と復帰閾値
- 共通冷却量と複数武器への配分規則
- 各武器のHeat発生量
- パリィ成功時の排熱量
- Heat警告表示を開始する値
