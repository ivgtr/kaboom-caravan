# ADR 0007: 方向入力と組み合わせる急加速

- Status: Accepted
- Date: 2026-08-11

## 決定

戦闘中の左`Shift`へ、入力中の移動方向に車両を短時間加速する「急加速」を割り当てる。

- 継続時間: 0.22秒
- 再使用時間: 2.7秒
- 最高速度: 通常の1.8倍
- Energy消費: なし
- 無敵時間: なし
- 攻撃: 急加速中も使用可能
- 発動条件: `A` / `D`または左右操作の方向入力があること
- 迎撃パリィとの同時発動: 迎撃パリィを優先し、急加速は発動しない

発動はキーを押した瞬間の1回だけ受け付ける。押しっぱなしやOSキーリピートによる再発動は行わない。終了時は通常の最高速度へ戻し、その後は既存の慣性移動へ接続する。

## 表現

車両の移動として読めるよう、キャラバンの小さなピッチ、車輪回転速度、排気煙の増加、進行方向と逆へ伸びる速度線、短い加速音を同期する。別キャラクターの歩行モーションや、車体全体の単純な平行移動にはしない。

左下の移動操作群へ専用ボタンを置き、再使用時間を同じ場所へ表示する。右下は主武器、副武器、迎撃パリィだけを維持し、攻撃と防御の親指操作を急加速で圧迫しない。

## 理由

副武器を左`Shift`から`C`へ移すことで、左手側に移動を補助する専用操作を追加できる。急加速は回避無敵ではなく位置取りの手段とし、攻撃を継続しながら敵との距離や前線リスクを素早く変える役割を持たせる。迎撃パリィは`F`に独立させ、敵の攻撃へ合わせる防御判断と移動判断を混同しない。

## 変更可能な数値

継続時間、再使用時間、速度倍率はプレイテスト対象とする。ただし、方向入力必須、無敵なし、攻撃可能、迎撃優先という役割は維持する。
