# BREAKOUT — 戦闘の目的を「全滅」から「突破」へ置き換える

## なぜこの変更をするか

これまで BREAK / Combat Core / DEATH RIDE / WANTED / REDLINE と判断要素を足してきたが、どれも最終的には同じループへ戻っていた。

```text
敵が来る → 武器を撃つ → HPを削る → 全滅するまで繰り返す
```

問題は機能不足ではなく、**勝利条件そのものが射撃連打を正解にしていること**にある。

このPRでは武器を増やさない。通常戦の目的を壊す。

## 新しい通常戦

Battle 1〜9 は敵の全滅では終わらない。

- 24秒の突破期限
- 62〜74mに「封鎖線」を置く
- 封鎖線へ入り、敵に塞がれていない状態を2.5秒維持すると勝利
- 敵が残っていてもその瞬間に離脱
- 逆に全敵を倒しても、封鎖線を抜けなければ戦闘は続く
- 期限切れは車体HPが残っていても敗北
- Battle 10のカワイイ・フォートレスだけは従来どおり撃破が勝利条件

寄り道の整備所 / 物資庫を選んだ戦闘では、従来の回収目標を優先する。まず通常ルートの核が成立するかを検証するための切り方。

## 何が変わるか

### Before

安全な距離を維持して、撃てる武器を撃ち続ければ最終的には勝てる。

敵を倒すこと自体が目的なので、武器選択はほぼDPS最適化になる。

### After

目的は「右側の出口をこじ開ける」こと。

- 後退し続ける = その場は安全でも期限が減る
- 前へ出る = 射程・敵密度・被弾リスクが上がるが勝利へ近づく
- 封鎖線にHeavyがいる = 倒す / BREAKさせる / DEATH RIDEで押し切る必要がある
- 後方のArtillery = 必ずしも倒さなくてよい。あと2.5秒耐えられるなら置き去りにできる
- Ammo 0 = REDLINEで敵を全滅させる必要はなく、出口を塞ぐ1体だけを退かせればよい

**「どの敵を倒すか」より「どの敵は無視できるか」が重要になる。**

## 既存システムの扱い

既存機能は削除していないが、主役から降ろす。

- BREAK: 封鎖線を塞ぐHeavyを短時間どかすための道具
- Combat Core: 突破方法の差を作る補助
- DEATH RIDE: 全滅必殺技ではなく、出口を数秒こじ開けるALL-IN
- WANTED: 出口へ向かう途中の障害密度を上げる
- REDLINE: 弾切れ後も「最後の1体だけ退かせる」ための賭け
- Frontline: 生存上の圧力として残すが、勝利条件ではない

評価対象は各システムの強さではなく、**それらを使わずにただ撃ち続けるプレイが最適でなくなったか**。

## 参考にした考え方

Burnout 3は危険運転そのものをBoostへ還流させ、単に速く走るだけでなく攻撃的な運転を中核へ据えた。DOOM Eternalも不足資源を待って回復するのではなく、敵へ近づいて奪う構造を採用している。

ここから借りるのは個別機能ではなく、**ゲームがプレイヤーへ求める方向を勝利条件と資源構造で固定する**考え方。

Kaboom Caravanでは「敵を倒す」ではなく「危険な側へ車を進める」ことを勝利条件そのものにする。

## このPRで意図的にやらないこと

- 新武器
- 新ゲージ
- 新必殺技
- RAM
- 敵HPやDPSの細かい再調整
- メタ進行の拡張

まず既存の戦闘資産だけで、勝利条件を変えた時にゲームが別物になるかを見る。

## プレイテスト判定

成功なら以下が起きる。

1. 敵を全滅させずに逃げ切る戦闘が普通に発生する
2. 「あのArtilleryは無視した」「Heavyだけどかした」という判断を説明できる
3. 画面右へ進むこと自体に緊張感がある
4. 全滅後に出口へ向かう時、「なぜまだ終わらないか」が直感的に理解できる
5. 従来のように安全圏で射撃を続けるだけではタイムアウトする

これが成立しない場合、次に触るのは武器バランスではなく、移動規則そのもの（常時前進 / 後退をブレーキ化 / 追跡型カメラ）とする。
