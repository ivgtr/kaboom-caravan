# DEATH RIDE / 決死突破

## 目的

PR #8 までで、距離・パリィ・BREAK・Combat Core・攻撃ビートによる「正しく戦うための判断」はかなり増えた。

一方、戦闘の成功体験は依然として漸進的で、上手く戦っても画面と状況が少しずつ有利になる範囲に収まりやすい。1回のプレイを記憶に残すには、プレイヤー自身が安全な戦況を壊し、短時間だけ異常な強さを得る瞬間が必要だと考える。

そこで既存の前線突破を、安全な切り返し技から **1戦1回のALL-IN「DEATH RIDE」** へ作り替える。

## 旧仕様から捨てるもの

従来の前線突破は発動時に以下を同時に行っていた。

- 敵弾を全消去
- 敵を大きく押し戻す
- 敵の攻撃予兆を中断
- 前線を8回復
- 両武器の熱・Cooldownを解消
- 4秒間の連射・排熱強化

攻守両面で失敗を帳消しにするため、危なくなった時に押すほど合理的な「保険」になりやすい。

DEATH RIDEでは保険部分を壊す。

- 敵弾は消さない
- 攻撃予兆を止めない
- 前線を回復しない
- 既存敵の押し戻しは小さくする

## 新しいルール

100%まで貯め、敵がいる状態で `E` を押すと発動する。

### 発動した瞬間

1. 既存敵を少しだけ後退させ、数秒の射線を作る
2. 武器の熱と射撃Cooldownを解消する
3. プレイヤーの近距離へ以下4体が即座に乱入する
   - ハナツノ
   - バクレツミ
   - モスモコ
   - ホウシダケ
4. 4秒間だけ火器Cooldown進行 **3.25倍**、排熱 **5倍**

敵弾・攻撃予兆・前線状態はそのままなので、発動そのものは安全を保証しない。

### 4秒後

DEATH RIDEで追加された敵を倒し切れなかった場合、その敵は消えない。そのまま通常戦闘へ残る。

つまり、発動時点でプレイヤーは「敵4体を追加する代わりに、4秒間だけ戦闘力を借りる」。借りた火力で負債を返せなければ、その後の戦場が発動前より悪化する。

## 1戦1回

同じ戦闘では再発動できない。

発動後も命中・パリィでゲージ自体は再充填でき、100%まで貯めた分は次戦へ持ち越せる。ただし、その戦闘中は再使用できない。

理由は2つ。

- 追加敵を何度も生成して物資・撃破トリガーを稼ぐループを防ぐ
- 「今この戦闘で切る」という決断を一度きりにし、記憶に残りやすくする

## Eliteとの整合

Elite進路でDEATH RIDEを使った場合、追加4体にも通常のElite補正を適用する。

「難しい進路で必殺技だけ通常敵を呼んで稼ぐ」という抜け道にはしない。

## 目指す感情曲線

通常戦闘:

`pressure -> BREAK -> finish -> breathe`

DEATH RIDE:

`100% -> 自分で戦場を壊す -> 4秒の暴力 -> 全滅させて快感 / 残して後悔`

重要なのは、発動が常に正解ではないこと。安全に勝てそうな戦闘なら押さない方が良い局面があってよい。

## プレイテストで見ること

1. 発動直後の4秒が通常戦闘と明確に別物に感じるか
2. 追加4体が「面倒」ではなく、強化火力を叩き込む標的として気持ちよいか
3. 倒し切れなかった時に、本当に自分の判断ミスだと感じられるか
4. 3.25倍 / 5倍がまだ弱いなら、躊躇せずさらに上げるべきか
5. 4体が多すぎる場合も、倍率を下げるのではなく敵構成・出現距離で調整できないか
6. Boss戦でDEATH RIDEを切るタイミングがプレイヤーごとに分かれるか
7. 一度も使わず勝つのが最適解になりすぎていないか

平均的な勝率だけで調整しない。**「押した瞬間に話のネタが生まれるか」**を最優先にする。
