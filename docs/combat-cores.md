# 改造コア：装備を拾う遠征から、戦い方を組み立てる遠征へ

## 狙いと既存PRとの関係

PR #1 は一時停止と操作ガイド、PR #2 は後にDEATH RIDEへ置き換えられる前線突破を追加した。
本変更はボタンや必殺技を増やすのではなく、**同じ装備でも何を狙って操作するか**を遠征ごとに変える。
最初の戦闘で既存操作を試した後、以降の装備選択に方針を与えるコアを1つ選ぶ。

敵の種類やルートを増やす案も考えられるが、今回は射撃・移動・パリィという既存の全戦闘に関わる操作を活かす。
報酬の乱数や入手武器に左右されず、序盤に必ず選択できる点を重視した。面白さや最適な倍率はプレイテストで評価する仮説であり、自動テストの成功と同一視しない。

## 遠征の導線

第1戦勝利 → 改造コア3択 → いつもの戦利品3択 → 第2戦。

コア選択は遠征中1回だけ。戦利品、引き直し回数、耐久回復、決死突破ゲージを消費せず、モジュール枠も使わない。
通常報酬は選択画面に入る時点で生成・保持し、コア選択によって再抽選しない。
選択はキーボード A/D・左右キー、Space/Enter、1〜3、またはカードのタップで行う。
選択前に Escape で閉じて進行不能になったり、背後の操作を行ったりできないよう、ネイティブのモーダル dialog を使う。

コアは遠征終了まで変更不可。次の遠征では未選択に戻る。永続保存には追加しない。

## コアとトレードオフ

| コア       | 行動と効果                                                                                               | 運用上の制約                                                                                                          |
| ---------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 連携機関   | 片方の武器を実際に撃ち、2.5秒以内に反対のスロットを撃つと、その斉射の威力1.6倍。直前の武器の熱を18排出。 | 主副を片方ずつ操作する必要がある。同時押しは、片方が冷却中・弾切れでも連携を解除する。                                |
| 展開砲座   | 25m以降で移動入力も惰性移動もない状態を1.5秒維持すると、斉射威力1.5倍、発熱30%減。                       | 停止位置と回避の判断が必要。移動入力・惰性移動・25m未満で即解除。画面端での移動入力も解除する。装甲・無敵は増えない。 |
| 反攻蓄電器 | 実際の接触攻撃または敵弾のパリィ成功で反攻弾1回分。3秒以内の次の斉射が威力2.5倍。                        | 重複不可。同時射撃は先に発射できた主武器が優先。重い副武器へ使うには主武器を止めてタイミングを合わせる。              |

すべて弾薬・電力・通常のCooldownを消費する。反攻弾でパリィそのものの反撃ダメージは増えない。
強化は既存の武器Lv・モジュール効果を反映した武器に1回だけ適用し、射程外減衰や敵装甲は従来どおり処理する。
斉射単位で処理するので、散弾・多段・貫通・爆発の命中数でコアを再発動しない。

連携機関は大型弾薬庫・追加発電機、展開砲座は戦術レーダー・追加装甲、反攻蓄電器は重い単発武器など、報酬画面で方針に合った装備のヒントを表示する。ただし専用装備の所持は発動条件ではない。

## 時間、順序、状態

新ルールは `simulation/combatCore.ts` に分離し、固定60Hzのシミュレーションだけが時間を進める。
射撃への適用は実際の車両移動の後。連携更新・排熱・反攻弾の消費は射撃が成功した場合にのみ確定する。
弾切れ・電力不足・Cooldown・過熱で撃てなければ、残り時間だけ進み、反攻弾は消費しない。

パリィによる反攻弾の装填はそのステップの射撃処理後に行う。接触パリィも敵弾パリィも同じ順序で、同時に射撃していても新たな反攻弾は次のステップ以降へ残す。
同時に複数の攻撃をパリィしても1回分。すでに持っている場合は残り3秒へ更新する。

コアの種類だけを次戦へ持ち越し、連携の最終スロット・残り時間、展開時間、反攻弾は各戦闘開始時にリセットする。
戦闘途中の武器箱では状態と時間を保持して再開する。一時停止・blur・報酬・進路・コア選択中に時間は進まない。
DEATH RIDEは独立して共存する。DEATH RIDEの火器Cooldown倍率でコアの時計は加速せず、発動そのものをパリィ成功として数えない。DEATH RIDEは敵弾を消去しないため、反攻蓄電器を狙うなら通常どおり実際にパリィする必要がある。

## 表示

コア名、次に狙う行動、準備・残り時間を小型HUDで表示する。移動・射撃・DEATH RIDE操作を覆わない位置に置き、連続するタイマー値をライブ通知しない。
展開完了と反攻弾装填には準備完了イベント、強化斉射には発動イベントを出す。準備完了は効果音も鳴らす。
詳細な条件は一時停止の操作ガイドで再確認できる。報酬画面と結果画面にも選んだコアを表示する。

## 検証

- `npm run check`：Lint、全単体テスト、TypeScript、本番ビルド、書式。
- `npm run test:e2e -- tests/e2e/pause.spec.ts tests/e2e/breakthrough.spec.ts tests/e2e/combat-core.spec.ts`：既存操作との回帰と新UI。
- `combatCore.test.ts`：時間・位置の境界、斉射単位の強化、同時押し、失敗射撃、実際のパリィ、資源と既存強化との共存。
- `combatCoreSession.test.ts`：第1戦の分岐、通常報酬保持、選択の検証、武器箱・次戦・ルート・再出撃。
- `mvpRun.test.ts`：3コア×シード1/42/2026で全10戦、実際の発動、DEATH RIDE、同一入力での再現性。

従来の固定シードテストは第1戦後に反攻蓄電器を選ぶよう更新し、通常の移動・射撃・報酬選択方針は維持する。追加ダメージにより討伐時刻・武器箱・以降の装備が変わるため、固定期待値もその結果へ更新した。以前の期待値がそのまま維持されたという意味ではない。
コア別の自動操作は連携の片側射撃、砲座の適正距離での停止を行う。遠距離から弾を浪費し続ける停止戦術を最適とは扱わない。

明示的な開発用URL：

- `/?debug&corePreview=choice`：第1戦勝利の実際のセッション遷移を通したコア選択。
- `/?debug&corePreview=relay`：40m・連携未開始。主副を片方ずつ撃つ。
- `/?debug&corePreview=siege`：40m・未展開。停止、移動、一時停止を比較する。
- `/?debug&corePreview=counter`：40m・反攻弾なし。30m先から来る敵弾をFで迎撃する。

戦闘プレビューの敵は検証用に静止・高耐久とし、波状出現は止めている。debug がなければプレビューは適用しない。
自動テストで進行と規則は検証するが、コアの選択率・操作の楽しさ・難度は未測定。特にタッチでの連携の扱いやすさ、展開と回避の判断、主武器が反攻弾を先に使う仕様の伝わりやすさをプレイテストの重点とする。
