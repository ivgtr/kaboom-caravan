# Kaboom Caravan UIテキスト用語ガイド

- Date: 2026-08-11
- Scope: 製品UI、操作表示、戦闘通知、結果画面

## 基本方針

- プレイヤーが意味を判断する表示は日本語を基本とする。
- `A`、`D`、`Q`、`SPACE`、`Lv.`など、実際のキー名と短い規格表記は英数字を使用する。
- タイトル固有語の`Kaboom Caravan`と`KABOOM・キャラバン`は名称として維持する。
- 画面幅が狭い操作ボタンでは「主武器／副武器／迎撃」を「主／副／迎撃」と短縮する。
- 同じ概念を画面ごとに言い換えない。

## 固定用語

| 意味             | 標準表記           | 短縮表記 |
| ---------------- | ------------------ | -------- |
| Primary Weapon   | 主武器             | 主       |
| Secondary Weapon | 副武器             | 副       |
| Parry            | 迎撃               | 迎撃     |
| Combat           | 戦闘               | 戦       |
| Run              | 遠征               | -        |
| Reward           | 戦利品             | -        |
| Treasure         | お宝               | -        |
| Reroll           | 引き直し           | -        |
| Module           | モジュール         | -        |
| Garage           | 整備庫             | -        |
| Victory          | 遠征完遂／戦闘勝利 | 完遂     |
| Defeat           | キャラバン大破     | 大破     |

## 文言の調子

- 操作前は「〜しよう」、即時通知は「〜した！」「〜接近！」と短くする。
- システム都合の「新しいラン」「選択する」「RUN COMPLETE」は使用しない。
- ボタンは行き先または結果が分かる「整備庫へ戻る」「これに決める」のような表現にする。
