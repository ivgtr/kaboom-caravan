# 前線突破（旧仕様）

この文書は PR #2 で追加した旧「前線突破」の設計記録です。

前線突破はその後、1戦1回のALL-IN **DEATH RIDE / 決死突破** へ作り替えられました。現在の仕様・意図・確認方法は [death-ride-breakthrough.md](death-ride-breakthrough.md) を参照してください。

## 旧仕様との主な違い

旧前線突破は、100%ゲージを消費して次の安全策を同時に得る切り返し技でした。

- 敵弾を全消去
- 敵を大きく押し戻す
- 攻撃予兆を中断
- 前線を回復
- 武器の熱・Cooldownを解消
- 4秒間の連射・排熱強化

現在のDEATH RIDEでは、敵弾消去・攻撃中断・前線回復を削除しています。代わりに敵4体を即座に追加し、4秒だけ極端な火器強化を得ます。追加した敵は時間切れでも消えません。

旧仕様を前提にした実装判断・テスト期待値を復活させる場合は、現在のゲーム体験を意図的に安全側へ戻す変更になる点に注意してください。
