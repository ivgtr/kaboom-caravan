# ROGUE SIEGE — 射撃を足さず、軍団を作るゲームへ

## 置き換える理由

PR #2〜#11は前線突破、コア、拠点目標、BREAK、DEATH RIDE、WANTED、REDLINEを積み重ねました。#12のRAM、#13のBREAKOUT、#14のACTION TIMEも比較しました。各案に違いはありますが、プレイヤーが直接車両を操って攻撃する前提は共通しています。今回の「ローグライク要素が混ぜられたにゃんこ大戦争」という方向性では、この前提から外れます。

旧: 移動・射撃・熱・弾薬を操作し、迫る敵を処理する。

新: 物資を前衛・後衛・大型・経済へ配分し、作った軍団が押し合う様子を見て次の生産を決める。

にゃんこ大戦争の公式操作説明にある、生産費・自然収入・働きネコへの投資・にゃんこ砲・敵城撃破という判断構造を参考にしています。キャラクター、画像、コード、固有名詞は借用していません。

参考: https://ponosgames.com/information/appli/battlecats/help/index.html

## スコープ

通常起動を新版へ置換します。選択式の追加モードや、シューティング中に召喚ボタンを追加する案ではありません。既存の自機移動・手動射撃・パリィ・熱・弾薬・RAM・REDLINE・DEATH RIDE・旧コア・旧進路は、新版の判断から外します。

旧コードは削除せず、`?legacyCombat` で明示した比較・回帰テスト用に遅延読み込みします。既存アート、横持ちのImmersiveShell、停止コントローラーを再利用します。依存・lockfile・永続セーブ形式・デプロイ設定は変えません。新版は旧版のアンロックや成績にアクセスしません。

## 1戦の核

- 左の母艦は固定、右の敵拠点を破壊すると勝利。母艦破壊は敗北、同時破壊も敗北です。
- 物資160、自然収入14/秒、財布320から開始。敵撃破で賞金が入ります。物資0でも時間で回復し、HPを弾薬へ変換しません。
- 補給は4回増資可能。費用90/165/240/315、各回の収入+7/秒、財布+170。初期表示がLv.1なので最大Lv.5です。
- 味方は最大36体、敵は最大32体。3体生産時に枠が足りなければ、費用を引かず全体を拒否します。
- 母艦砲は初期充填100%、通常25秒で再充填。敵拠点には当たらず、敵にダメージ・押し戻し・溜め中断。無敵や補修ではありません。
- 次の増援の役割と残り時間を表示。敵拠点50%で3秒の反撃予告後、守備隊長と護衛が出ます。隊長枠を通常増援から予約し、上限によって消えないようにします。3秒以内に城を落とせれば反撃を待たず勝利です。
- 90秒から増援間隔が4.5秒に短縮。安全に永久増資する待ち戦略は成立しません。

## 4兵種の役割

| -------------- | -------: | ------------------------------------------------------------ |

| ラッシュバギー |       80 | 安い速射火力を足して、単体を早く削る                         |
| ドカン砲車     |      145 | 壁の後ろから範囲攻撃。14未満の近距離は死角で、前衛崩壊に弱い |
| 鉄くずタイタン |      300 | 貯めるまで部隊を我慢し、一体で戦線を大きく動かす             |

試走で砲車だけの生産が強すぎたため、基本威力を64から48へ変更し、近距離の死角を設けました。砲車特化の改造が揃えば単兵種で勝てる展開は残しています。「どの組み合わせでも同じボタンで勝てる」と「今回は壊れた特化軍団を作れた」は区別します。

## 遠征を壊す9改造

最初はSWARM / SIEGE / TITANの固定3択。最初の戦闘から戦い方を変え、強い報酬を拾うまで平凡な戦闘を要求しません。以降は未取得からシード付き抽選で3択、6戦目までに6つが重なります。同一改造の重複はありません。

例えばSWARM×誘爆なら「壁を失わない」だけが正解ではなくなります。パレードを重ねれば壁の密集が後衛の連射へ直結し、低耐久の集団が敵範囲攻撃で崩れる危険も増えます。砲車の一発、タイタンの接敵、壁の誘爆で、見ている戦線が変わることを目標にします。

## 実装の境界

`src/game/siege` は描画・音・実時間から独立した純粋な固定30Hzシミュレーション。入力は次の固定ステップへ一度だけ渡し、長押し/リピートで自動生産しません。全攻撃のダメージをまとめて適用し、同じtick内で配列の先頭側だけ先制しないようにします。死亡時処理は各IDにつき一回、爆発連鎖にも再帰的な生産はありません。

乱数は明示seedのxorshift。実時間による乱数・描画依存の判定はありません。同じseedに加えて同じtickの入力と同じ改造選択が再現条件です。seedだけで人間の操作差まで同じになるという意味ではありません。

DOMで位置・HP・攻撃予兆・押し戻しを描画し、元の装備アートを味方車両、元の敵アートを敵部隊に利用。効果音は入力で解錠する小さいシンセ。音が拒否されても操作は継続します。描画上のエフェクトは最大40個、両軍の個体数も上限付きです。

戦闘以外・一時停止・非表示・縦長中はシミュレーション、収入、入力キューを停止。復帰時の実時間を一気に追いつかせません。ネイティブdialogで改造・停止・結果のフォーカスを隔離し、タップ、数字キー、Tab/Enterに対応します。縮小アニメーション設定では演出アニメーションを停止します。

## 検証と、その限界

単体テストは費用/CD/枠の原子性、投資、全改造、砲車の死角、範囲攻撃、誘爆と賞金の一回性、母艦砲、反撃予告・予約枠、勝敗優先、遠征引継ぎ、停止、入力非破壊を確認します。

3開始方針×seed1/42/2026の9通りについて、実際に資金を使い、壁・後衛・大型・母艦砲を組み合わせるスクリプトで全6戦完走と再現性を確認します。HP・資金・ダメージをテスト用に上乗せして完走させるものではありません。

比較用の待機・増資のみ・各単兵種・全兵種順番連打も同じ9条件で試します。これは限定した方策の比較であり、全ての連打方策に対する数学的な優位性の証明ではありません。砲車特化で勝つ条件は残っています。スクリプトは状況を正確に読めるため、その勝率を人間の難易度や楽しさと同一視しません。

新E2Eは通常URLから開始し、実際のDOM操作・固定時計による戦闘進行、最初の拠点の撃破と次戦、敗北・同seed再挑戦、停止・blur・回転・タッチを確認します。戦闘ステートの裏書きで勝利させません。旧版テストはURLだけをlegacyへ変更し、既存の期待値は維持します。

### 人間によるプレイテストで見ること

1. 「今は壁より増資」「一体我慢してタイタン」と判断を説明できるか。
2. 砲車の死角が理不尽な停止ではなく、前衛を失った結果として分かるか。
3. 50%反撃の予告を見て、母艦砲や出撃資金を温存するか。
4. 一斉撃破・誘爆・大型の押し込みを、1ランの出来事として覚えているか。
5. タッチ端末で軍団が密集しても敵味方・予兆・物資が読めるか。

実プレイヤーによる面白さの評価、実機iPhone/Safariでの触感、9改造の選択率・最適バランスは未確定です。現在の音声は最小限のシンセで、専用の味方キャラクターアニメーションや進行セーブも対象外です。
