# Kaboom Caravan

**跳ぶ。壊す。当てる。スコアが暴れ出す。**

宝箱の当たりを重ねて、自己ベストのスコアを追うワンボタン・ランナーです。宝箱 → 能力 → 着地破壊 → 黄金の宝箱 → RUSH / HYPER、という連鎖を育てます。

## 遊び方

- タップ / Space / ↑ / W でジャンプ。短く押すと低く、長押しすると高く跳びます。空中でもう一度押すと一回だけ立て直せます
- 宝箱は走りながら自動で1〜3個の能力を抽選。大きなリールが順番に止まり、表示された能力がその場で有効になります。通常の抽選中も操作と走行は続きます
- **BOOST** は本当に速くなる加速装置。重ねるとジャンプのテンポも上がります
- **LANDING BOMB** は着地で道を破壊する衝撃波。加速と組み合わせるほど遠くまで届きます
- **GOLD INFECTION** は敵や破壊箱を黄金化。黄金の相手を壊して次の宝箱を作ります
- **MAGNET** は宝箱とスクラップを引き寄せ、さらに当たりをつなげます
- 連続破壊で RUSH、さらに続けて HYPER。スコアは **速度 × 破壊チェイン × 能力の組み合わせ × RUSH / HYPER** で膨らみます。距離は補助記録です
- レアな JACKPOT では0.65秒だけ世界が止まる FREEZE。解除と同時に走りが戻ります。この間の押下・離す入力も受け付けます
- 武器は自動攻撃。スクラップは火力とガードの改造にも使います。宝箱は拾うもの、道の補給箱は壊すものです。穴には落ちます
- Esc / P または一時停止。タブ移動、フォーカス離脱、縦横切り替えでも停止し、明示的な再開を待ちます。中断時は押下状態を解除します
- 「もう一度」は同じ道と抽選シード。「新しい道」は別のシード。最高スコアを端末内に保存します。URLの `?seed=42` でも固定できます

## 演出と実装

パチンコの予告・段階開示・昇格・連続当たりの構造を、実際に獲得した能力の演出に使っています。課金・賭け金・換金はありません。演出用の偽の抽選もありません。大量の箱はまとめて開示し、無限の待ち列にはしません。

速度は初速330px/sから、ブースターで最大1650px/sまで上がります。120Hz固定物理のまま速度を変え、地形生成・衝突・カメラも対応。ジャンプのテンポは踏み切り時に確定するので、空中で強化しても弧が突然変わりません。FREEZE以外では演出で世界を止めません。

既存の手描き車両と岩肌に合わせた、新しい宝箱・真鍮の抽選機・能力装置の絵を使用。[原画と書き出し情報](artifacts/score-fever/manifest.json)。音は独自のWeb Audio合成です。宝箱の始動・加速する回転音・実際の停止を分け、追加報酬だけが上昇するフレーズにつながります。RUSH/HYPERには別の合図、FREEZEの無音の後には大当たり専用の低音・金属音・ファンファーレ。当たり中はBGMや細かな戦闘音を引かせ、音量と同時発音数を制限します。ミュート・背景移動・停止で演出音を持ち越しません。画面全体の連続点滅は使わず、動きを減らす設定を尊重します。

## 開発

Node.js 24以降。

```bash
npm ci
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
```

重要な物理・抽選・スコア・上限制御のユニットテストと、実際のキー／タッチ入力・FREEZE・中断・リトライのブラウザ検証に絞っています。音は実際のWeb Audio波形でも検証します。入力リプレイの成功は、人間による「楽しい」の評価や聴感評価とは別です。PRのマージと公開も別操作です。
