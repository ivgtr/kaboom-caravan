# Kaboom Caravan — ENDLESS RUN

**跳んで。拾って。どこまでも。**

自動で走り続けるキャラバンで、坂を走り、細い足場を跳びつなぎ、自己ベストの距離を伸ばすワンボタン・エンドレスランナーです。ガラケー時代のジャンプランのシンプルさに着想を得た、独自の物理とコースです。

## 遊び方

- 画面タップ / Space / ↑ / W でジャンプ。高さは一定、空中の追加ジャンプはありません
- 坂はそのまま走れます。細い足場では着地直前のタップも受け付け、着いた瞬間に次のジャンプへ。押しっぱなしでは連続ジャンプしません
- 空中の武器を狙うか、低い道で今の武器をキープするか。武器は自動でライバルを攻撃します
- 武器は160m有効。同じ武器はLv3まで強化して期限を更新、違う武器はLv1で交換します
- 6種の武器、シールド、スクラップ磁石が登場。装備はジャンプの高さや走行速度を変えません
- 穴・上り段差の壁・木箱でラン終了。ライバルとの接触はシールドが1回防ぎます。シールドで落下は防げません
- ライバルは時々現れる追い越し相手。全員倒す必要も、ゴールもありません
- Esc / P または一時停止ボタンで休憩。タブ離脱・フォーカス離脱・画面の縦横切り替えでも停止し、明示再開を待ちます
- 縦持ち・横持ちに対応。結果画面の「もう一度」は同じ道、「新しい道」は別のラン。最高距離は端末内に保存します

URLの `?seed=42` で道とドロップを固定できます。ジャンプに90msのコヨーテタイムと100msの先行入力を設け、速度は220→340px/sまで緩やかに上がります。地形は坂・段差・細い連続足場を短いリズムとして組み立て、その間に休める道を配置します。描画と衝突は同じ斜面を使い、坂でも水平速度とジャンプの強さは変わりません。細い足場には長い助走を要求せず、着地位置と次の入力を引き継いで出口まで通れるかを検証します。カメラはジャンプに追従せず、次の着地点を固定して見せます。距離の腕前が主役で、スクラップは別集計です。

生成方式は[Canabaltの速度・段差・穴幅の連動](https://github.com/ninjamuffin99/canabalt-hf/blob/a1f44cc39275474b644cea63b30a553c71f235fc/source/Sequence.hx#L127-L177)、斜面は[tiny-wingsの描画と衝突を共有する地形](https://github.com/haqu/tiny-wings/blob/master/tiny-wings/Game/Objects/Terrain.mm#L303-L479)、先行入力は[Celeste Classic](https://github.com/NoelFB/Celeste/blob/master/Source/PICO-8/Classic.cs#L203-L306)、区間構成は[Launchpadのリズム先行生成](https://mtreanor.com/publications/Smith-Launchpad-TCIAIG-2011.pdf)を調査しました。操作モデルの異なる作品のコードや定数を移植せず、本作の固定ジャンプで組み立てています。

## 開発

Node.js 24以降。

```bash
npm ci
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
```

Canvas 2Dで描画し、物理は120Hz固定更新。テストはジャンプ・生成地形・装備・中断/再開の要所に限定しています。旧攻城戦/シューティングの実装は置き換え、元のイラスト素材と過去の設計資料は残しています。PRのマージ・公開は別操作です。
