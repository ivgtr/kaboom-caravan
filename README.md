# Kaboom Caravan — ROGUE SIEGE

![キャラバンとモンスター軍団](docs/assets/key-visual.png)

> 自分で撃たない。軍団をつくれ。城を壊せ。

**物資で部隊を出撃させ、左の母艦を守りながら右の敵拠点を壊す、全6戦のローグライク攻城戦。** 通常起動の戦闘を、自機操作のシューティングから軍団の生産・資金配分・戦線管理へ置き換えました。

最初から「壁が3台ずつ出る」「砲車の一撃が2.5倍になる」「巨大タイタンへ集中投資する」の3択で始まります。勝利ごとにランダムな改造3択。改造は重なるため、量産した壁が爆弾になる、集団で攻撃間隔が縮む、といった偏った軍団を作れます。全ての改造に代償があります。

## 遊び方

物資は自然回復し、敵撃破でも増えます。壁・バギー・砲車・タイタンの4兵種は出撃後に自動で移動・攻撃します。**砲車の足元は死角**なので、前衛で守りましょう。増資すれば収入と財布が増えますが、その資金で出せた部隊を我慢することになります。

敵拠点の耐久が50%になると3秒後に守備隊長が反撃します。母艦砲は全敵を押し戻し、溜め攻撃を中断する切り返しです。温存するか、敵の群れを今崩すかを選びます。90秒からは増援間隔が短縮します。

敵拠点を壊せば、敵が残っていても勝利。敵を全滅させただけでは終わりません。母艦が壊れたら遠征終了です。勝利後は改造・母艦耐久・遠征統計を持ち越し、母艦を100補修。部隊・物資・補給Lv・一時状態はリセットします。

| 操作       | キーボード                 | タッチ               |
| ---------- | -------------------------- | -------------------- |
| 部隊出撃   | `1`〜`4`                   | 下部の兵種をタップ   |
| 補給に増資 | `Q`                        | 補給ボタン           |
| 母艦砲     | `E`                        | 母艦砲ボタン         |
| 改造選択   | `1`〜`3` / `Tab` + `Enter` | 改造をタップ         |
| 停止・再開 | `Esc` / `P`                | 一時停止・戦闘を再開 |

長押しによる自動出撃はありません。横持ち専用です。タブ離脱・ウィンドウ離脱・縦持ちで戦闘と収入が停止し、戻っても明示再開を待ちます。途中セーブと新版の永続アンロックはありません。結果画面から同じSEEDで再挑戦できます。URLに `?seed=42` を指定すると初期条件を固定できます。

## 開発・検証

Node.js 24以降。

```bash
npm ci
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e -- tests/e2e/siege.spec.ts
```

通常URLで新版が起動します。この変更はPRをマージしてデプロイするまで公開サイトへ反映されません。

旧版は比較・回帰検証のため `/?legacyCombat` でのみ起動します。旧版の説明は [旧シューティング版](docs/legacy-shooter.md)。過去の戦闘テストはこの明示URLへ移し、通常起動の新版には専用E2Eを追加しています。

設計意図・調整値・検証範囲・残るプレイテスト項目は [軍団攻城戦の設計](docs/rogue-siege.md) を参照してください。
