# Kaboom Caravan

**跳ぶ高さを選んで、武器を育てて、もう少し先へ。**

イラストのキャラバンで坂道と穴を越える、ワンボタンのエンドレスランナーです。

## 遊び方

- タップ / Space / ↑ / W でジャンプ。短く押すと低く、長押しすると高く跳びます。上昇中に離すと高さと飛距離を抑えられます
- 空中でもう一度押すと、着地まで一回だけ立て直しジャンプ。着地で回復します。押しっぱなしでは連続ジャンプしません
- 武器は自動攻撃。地上の最初の武器ですぐに試せます。その後は空中の武器を取るか、低い道で現在の武器を保つかを選びます
- 武器はランが終わるまで有効。同じ武器で強化され、別の武器へ替えてもそれぞれの強化段階を覚えています
- 連射・散弾・爆風・貫通・火炎・近接爆弾は、敵の並び方と距離で得意場面が違います。木箱も壊せますが、武器なしで跳び越えることもできます
- スクラップを集めると改造段階が上がり（最初は25個、次は累計60個）、全武器の火力・連射速度が上がってガードも回復します。穴は装備では埋まりません
- Esc / P または一時停止で休憩。タブ移動、フォーカス離脱、縦横切り替えでは停止し、明示的な再開を待ちます。押下状態は中断時に解除します
- 「もう一度」は同じ道。「新しい道」は別の道。最高距離を端末内に保存します。URLの `?seed=42` で道を固定できます

## コースと手触り

序盤の簡単な穴から、広い着地点・坂・高さ違いの穴へ短い間隔で進みます。速度は330→440px/s。一般の着地点は広く取り、細い足場は後半の短いアクセントに限定しています。新しい道では序盤の学習後から展開が変わります。

物理は120Hz固定更新。描画と衝突は同じ地形を使います。コヨーテタイムと先行入力を設け、可変ジャンプと空中ジャンプを実際の積分器で検証します。車体の大きさと接地幅を近づけ、回転するホイール、路面の流れ、砂煙、エンジン音で速度と接地を伝えます。動きを減らす設定を尊重します。

スクラップは改造の進捗として表示し、ランの成長に使います。ライバルは安全な一本道だけでなく、坂や木箱も含む短い遭遇パターンで登場します。装備を選んで楽に抜けるか、ジャンプでかわすかを選べます。

## 開発

Node.js 24以降。

```bash
npm ci
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
```

Canvas 2Dで描画。テストは物理・生成・装備の重要な契約と、実際のキー／ポインター入力・中断・リトライに絞っています。入力リプレイは動作確認であり、人間による「楽しい」の評価とは別です。PRのマージと公開は別操作です。

元の生成イラストを使い、地面は岩肌と路面端の2枚のWebPを地形に沿って繰り返します。[地形素材の生成・書き出し情報](artifacts/runner-terrain/manifest.json)。過去の設計資料は旧モードの記録であり、現行ルールはこのREADMEと実装を参照してください。
